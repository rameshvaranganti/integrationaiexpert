A RAG-Based Joule Copilot Framework on SAP BTP with CPI and API Management for SAP SuccessFactors

Rameshkumar Varanganti

International Journal of Human Resources Development and Management, Vol. 3, Issue 2, pp. 1–21, 2025 · IAEME Publication

Download PDF DOI: 10.34218/ijhrdm_03_02_001

Abstract

Presents a retrieval-augmented generation (RAG) framework that grounds SAP Joule copilot answers in enterprise HR content, using SAP BTP, SAP Cloud Integration (CPI) and SAP API Management to connect SAP SuccessFactors securely. The paper also covers governance, privacy and Zero Trust considerations for HR policy intelligence.

Keywords

SAP SuccessFactors; SAP Cloud Integration (CPI); Retrieval-Augmented Generation; SAP Build AI; SAP Joule; SAP BTP; HR Policy Intelligence
